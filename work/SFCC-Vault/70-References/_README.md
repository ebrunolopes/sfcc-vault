# References

## Why this folder

SFCC documentation moves. Anthropic's training data ages. Your reference notes are the version *you* understood, with the bits that mattered to your work highlighted.

## Conventions

- Always link to the source URL
- Paraphrase, don't quote at length
- Date the note — SFCC docs change with each release
- Flag deprecations explicitly
